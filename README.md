# 航班价格趋势与降价监控

一个本地运行的 Edge / Chrome 扩展：按城市和连续日期范围监控去哪儿网航班价格，发现具体航班降价或达到心仪价格时，通过浏览器和 PushPlus 微信通知提醒。

## 功能

- 自由选择出发城市和到达城市，内置 100+ 国内城市机场代码。
- 连续监控 1–7 天，每个日期独立检查，固定每 5 分钟一次。
- 可只看直飞，也可记录中转方案。
- 按“日期 + 航班号 + 起降时间”追踪具体航班，不把不同航班混在一起。
- 可设置心仪价格；低于或等于目标价时提醒。
- 具体航班降价、当日最低价下降时提醒，并避免相同价格反复轰炸。
- 日期范围最低价概览、单航班历史趋势图和价格记录表。
- Windows / 浏览器桌面通知，以及可选的 PushPlus 微信通知。
- 检查超时、连续失败恢复、安全验证提示和独立日期状态。
- 严格区分正式票价与优惠券、红包、立减金额，避免把促销数字误报为最低价。
- 后台检查完成后自动关闭扩展创建的临时查询页，避免长期占用内存；验证码页会保留。
- 数据仅保存在浏览器扩展本地存储；源码不包含任何个人 Token。

## 安装

1. 下载本仓库：点击 GitHub 的 **Code → Download ZIP**，解压到一个不会被删除的文件夹。
2. 在 Edge 地址栏输入 `edge://extensions`；Chrome 输入 `chrome://extensions`。
3. 打开右上角的“开发人员模式”。
4. 点击“加载解压缩的扩展”，选择本项目的 `extension` 文件夹。
5. 安装完成后，点击工具栏扩展图标，再点击“打开完整面板”。

更新源码后，在扩展管理页点击此扩展的“重新加载”即可。不要删除或移动 `extension` 文件夹，否则浏览器会找不到扩展。

从 2.0.0 升级到 2.0.1 时，会清空旧解析器留下的不可靠价格历史并重新采集；路线、日期、提醒设置和 PushPlus Token 会保留。

## 使用

1. 在完整面板选择出发城市、到达城市和 1–7 天日期范围。
2. 选择是否“仅监控直飞”，按需要开启“心仪价格”。
3. 如果需要微信通知，把自己的 PushPlus Token 填入本机设置，并点击“测试微信通知”。
4. 点击“保存设置”，再点击“立即检查全部”。
5. 首次运行会为每个日期临时打开去哪儿查询页，检查结束后自动关闭。若页面要求验证码，对应页面会保留，请手动完成一次。
6. 保持 Edge / Chrome 运行。浏览器完全退出后，扩展不会在后台检查。

扩展固定每 5 分钟检查一次。日期越多，需要轮询的查询页越多；为了降低被网站限流的概率，1–7 天的任务会错峰启动。

## 趋势与提醒规则

- 每个航班价格变化时记一条；价格不变时，每小时最多保留一个心跳点。
- 每班最多保留 240 个样本，历史最长保留 90 天，最多保留 300 条航班序列。
- “降价提醒”比较同一班航班上一次记录的价格。
- “心仪价格”首次达到目标价会提醒；只有继续出现更低价格时才会再次提醒。
- 切换出发地或目的地时会清空旧路线的趋势，避免数据串线。

## PushPlus

PushPlus 是可选第三方服务。Token 只写入浏览器扩展本地存储，不会提交到本仓库。普通额度是否足够取决于服务方当前规则；扩展只在满足提醒条件或连续失败时推送，不会每 5 分钟都发一条微信。

如果 Token 曾公开发送或误提交，请立即前往 PushPlus 重新生成，旧 Token 应视为已经泄露。

- 网站可能触发验证码、登录或访问频率限制，扩展不会绕过安全验证。

## 开发

只需要 Node.js 18+：

```powershell
npm test
```

项目不加载远程脚本，也没有运行时 npm 依赖。核心规则和页面文本解析均可在 Node.js 中单元测试。
